## 3. UI 애니메이션 (DOTween)

> **방침**: 현재 SetActive 즉시 전환 → DOTween 페이드·슬라이드 효과 추가

### 3-1. 적용 대상

| UI | 현재 | 개선 목표 |
|----|------|---------|
| 팝업 전체 (GameEndUI, BuildingPopup, ProductionPopup 등) | SetActive 즉시 | DOFade + DOScale 등장/퇴장 |
| 로비 탭 전환 | 즉시 전환 | 슬라이드 또는 페이드 |
| 생산 패널 슬라이드 업 | 즉시 등장 | DOAnchorPosY 슬라이드 |
| 건물 배치 팝업 | 즉시 등장 | DOScale punch 등장 |
| 로비 복귀 카운트다운 텍스트 | 즉시 표시 | 숫자 감소 애니메이션 |
| RematchRequestPopup | SetActive 즉시 | DOFade 등장 |
| LoadingScreen | DOFade (완료) | ✅ 이미 구현됨 |

### 3-2. 공통 패턴 (구현 시 적용)

```
등장: DOFade(0→1, 0.2f) + DOScale(0.9→1, 0.2f) + SetEase(Ease.OutBack)
퇴장: DOFade(1→0, 0.15f) + SetEase(Ease.InQuad) + OnComplete(SetActive(false))
슬라이드: DOAnchorPosY(offscreen→target, 0.25f) + SetEase(Ease.OutCubic)
```
