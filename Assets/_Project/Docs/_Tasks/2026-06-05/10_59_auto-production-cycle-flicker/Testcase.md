# Testcase — 자동생산 완료 사이클 슬롯2 깜빡임 버그 수정

작성일: 2026-06-05

---

### TC-1: 자동생산 1종 — 생산 완료 시 슬롯2 깜빡임 없음

**전제:** 유닛 1종(예: Pistoleer)을 자동생산 등록. 슬롯1에서 생산 중이고 슬롯2는 비어있는 상태.

**동작:**
1. 자동생산이 진행되어 유닛 한 마리가 생산 완료될 때까지 기다린다.

**기댓값:**
- 생산 완료 순간 슬롯2에 아이콘이 나타났다 사라지는 깜빡임이 없다.
- 슬롯1은 즉시 다음 생산을 시작하고, 슬롯2는 계속 비어있는 상태를 유지한다.

**결과:** PASS (2026-06-05 실기 확인)

---

### TC-2: 자동생산 1종 — 연속 생산 사이클 반복

**전제:** 유닛 1종 자동생산 등록. 생산이 반복되는 상태.

**동작:**
1. 여러 번 생산이 완료되는 것을 지켜본다 (3회 이상).

**기댓값:**
- 매 생산 완료 시마다 슬롯2 깜빡임이 없다.
- 슬롯1이 쉬지 않고 연속으로 생산을 이어간다.

**결과:** PASS (2026-06-05 실기 확인)
