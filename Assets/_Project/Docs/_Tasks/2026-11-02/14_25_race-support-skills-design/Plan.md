# Plan — 종족별 지원 스킬 기획 확정과 제작 단계

## 이 문서는 무엇인가

세 종족의 스킬 건물에 들어갈 **진짜 스킬 목록**이 2026-11-02 사용자 결정으로 정해졌다. 이 계획서는 그 목록을 **표 하나로 정리**하고, 스킬마다 **무엇을 새로 만들어야 하는지**(게임 기능과 이펙트), 그리고 **어떤 순서로 만들지**를 적는다.

만드는 순서는 사용자가 정했다 — 「스킬 vfx와 관련된 작업은 vfx를 기획 -> 제작 -> 코드 구현 -> 밸런싱으로 진행할 거야」. 즉 스킬 하나마다 **① 이펙트를 어떻게 보일지 정하고(VFX 기획) → ② 사용자가 Unity AI로 이펙트를 만들고(VFX 제작) → ③ 게임 기능을 코드로 붙이고(코드 구현) → ④ 숫자를 맞춘다(밸런싱).** 코드 구현 안에서는 다시 **지금 스킬 시스템으로 바로 만들 수 있는 것(1차)**부터, **새 기능이 필요한 것(2차)**, 그중 가장 위험한 **연막탄은 2차 맨 끝**, 아직 기획이 덜 된 **원소 공명은 그 이후** 순서로 간다. 첫 출시는 2차까지다.

슬롯 순서도 세 종족이 같은 규칙으로 맞췄다(1-0절). **일시 타격(발동 순간 한 번 터지는 것) → 지속 범위(구역이 남아 있는 동안 효과가 이어지는 것) → 강화(아군 버프)** 순이고, 같은 분류 안에서는 강화든 타격이든 **유닛 · 건물 모두에 걸리는 것 → 유닛에만 걸리는 것 → 건물에만 걸리는 것** 순이다. 아군을 강화하는 스킬은 모두 **맵 전체 아군**에게 걸리고, 효과를 받는 유닛·건물마다 이펙트가 붙는다.

구체적인 숫자(피해량 · 범위 · 쿨다운 · 지속 시간 · 확률)와 **적 건물에 주는 피해를 얼마나 줄일지**는 **이 계획에서 정하지 않는다** — 밸런싱 단계에서 정한다(사용자 결정). 규칙 문서(`GameSystemRules_Skills.md`) 본문도 **이번에는 고치지 않았다.** 고쳐야 할 곳은 6절에 목록으로만 두었고, 사용자 승인 뒤에 반영한다.

현재 코드 상태와 근거(파일 · 행)는 [Research.md](Research.md)에 있다. **구현은 이 Plan을 사용자가 승인한 뒤에만 시작한다**(WORKFLOW [4]).

## 1. 확정 스킬표 (3종족 × 슬롯)

### 1-0. 슬롯 정렬 규칙 `[확정]`

사용자 원문(2026-11-02): 「일시 타격 -> 지속 범위 -> 강화 순서로 정렬을 통일하자」, 「정렬에서 같은 종류의 경우 유닛 -> 건물 순으로 정하자, 이 정렬 관련 순서도 문서에 기록하도록 해줘」, 「유닛이나 건물을 강화하든 타격하든 유닛·건물 모두 적용 -> 유닛에만 적용 -> 건물에만 적용 순으로 정렬하도록 하자」(세 번째가 두 번째를 대체).

슬롯 1~5는 아래 순서로 채운다. 위 칸이 먼저 적용되고, 같으면 다음 칸으로 가린다.

| 순서 | 기준 | 내용 | 근거 |
|---|---|---|---|
| ① | **분류** | **일시 타격 → 지속 범위 → 강화** | 사용자 원문(위 첫 번째) |
| ② | **대상** | 같은 분류 안에서 **유닛 · 건물 모두 → 유닛만 → 건물만**. 강화(아군)든 타격(적)이든 같다 | 사용자 원문(위 세 번째) |
| ③ | **같은 그룹 안** | ① · ②가 같으면 **기존 순서를 유지**한다 | 메인 세션 지시 |
| ④ | **보류** | 기획이 보류된 스킬(원소 공명)은 **맨 뒤** | 메인 세션 지시 |

> **③의 「기존 순서」가 무엇인지** `[사실 — 메인 세션 재정렬 결과 대조]`: 메인 세션 결과에서 초월 「모두」 그룹은 2 재생의 뿌리 · 3 신목의 각성이다. 이는 바로 앞 판(결정 9 기준 4 재생 · 5 신목)의 순서이고, 첫 판(4 신목 · 5 재생)의 순서는 아니다. 유닛만 그룹(포효 · 순풍)과 인간 · 정령은 두 기준 어느 쪽이든 결과가 같다.
>
> **대체된 ② (2026-11-02, 같은 날 위 세 번째 원문으로 대체 — 원문 보존):** 「② 대상 — 같은 분류 안에서 **유닛 대상 → 건물 대상**. 유닛과 건물을 **모두** 대상으로 하면 **건물 대상 쪽**으로 센다 — 사용자 원문 「정렬에서 같은 종류의 경우 유닛 -> 건물 순으로 정하자 …」. 「모두 대상이면 건물 쪽」은 `[메인 해석 — 사용자 확인 필요]`(O-17)」. 그때의 ③은 "보류는 맨 뒤", ④는 "①~③이 같으면 첫 판 순서 유지"였다.

분류의 뜻과, 그 분류의 효과가 누구에게 걸리는지(O-3 결정):

| 분류 | 뜻 | 대상 판정 |
|---|---|---|
| **일시 타격** | 발동(착탄) 순간 한 번 효과를 내고 사라진다 | 발동(착탄) 순간 범위 안에 있던 대상에게만 |
| **지속 범위** | 구역이 남아 있는 동안 효과가 이어진다 | 구역에 들어오는 대상에게도 걸리고, 나가거나 구역이 끝나면 풀린다 |
| **강화** | 아군 버프 | 맵 전체 아군(O-4) |

각 스킬이 어느 분류 · 대상인지는 **메인 세션의 분류안**이다. 그중 서리 감옥(지속), 화염의 축복 · 대지의 갑주(맵 전체), 재생의 뿌리(유닛 · 건물 — 사용자 원문 「재생의 뿌리는 건물도 포함하자」)는 사용자가 직접 정했다.
