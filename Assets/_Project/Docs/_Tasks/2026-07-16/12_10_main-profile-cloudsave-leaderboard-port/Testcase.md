# Testcase - main profile cloud save leaderboard port

## 검증 결과

### PASS

- 이메일 회원가입 후 인증 대기 화면으로 이동한다.
- 이메일 인증 완료 후 최초 로그인 시 닉네임 설정 화면이 표시된다.
- 닉네임 설정 후 로비로 진입할 수 있다.
- Profile 탭에서 프로필 버튼 클릭 이벤트와 ProfileView 표시 경로가 동작한다.
- Profile 탭에 이메일, 닉네임 코드, 전적, 내 랭킹, 닉네임 변경 버튼, 로그아웃 버튼이 표시된다.
- NicknameChangePopup이 Profile 탭 위에 모달로 표시된다.
- Ranking 탭에 랭킹 테이블 헤더와 빈 상태 문구가 표시된다.
- 숨겨진 RankingView가 로비 진입 시 자동으로 데이터를 로드하지 않는다. 랭킹 데이터 로드는 Ranking 탭 표시 또는 새로고침 버튼 경로에서 수행한다.

### 보류 / 후속 작업

- UI 세부 배치, 알파, 버튼 크기 등 픽셀 단위 조정은 Unity Inspector에서 후속 튜닝한다.
- 이메일 인증 대기 화면의 `[이메일 주소]` 표시가 가입/로그인 시도 이메일을 명시적으로 반영하도록 수정해야 한다.
- 인증 메일 발송 후 사용자가 인증을 완료하지 않고 되돌아가는 경우의 Firebase 미인증 계정 처리 정책을 구현해야 한다.
