# Testcase — UI 색상/레이아웃 FAIL 9건 수정

## 작업 요약 (자연어)

이번 작업은 2026-05-27 게임 화면 UI 테스트에서 FAIL로 기록된 9개 항목을 한 번에 모두 수정하기
위한 것입니다. FAIL의 원인은 크게 두 가지입니다.

1. 색상이 코드 곳곳에 하드코딩되어 있어 일관성이 없고 디자이너가 수정할 수 없는 문제.
2. 일부 UI 요소가 절대 크기(픽셀 단위)로 만들어져 있어, 다양한 해상도의 모바일 기기에서
   화면 비율에 맞게 적절히 늘어나지 않는 문제.

이 작업으로 다음과 같은 변경이 일어났습니다.

- 프로젝트에 `UIColorConfig` 라는 새로운 색상 설정 에셋을 만들었습니다.
  모든 UI 코드에 있던 빨강/초록/하늘색 등 하드코딩 색상이 이 에셋의 항목을 참조하도록 바뀌었고,
  앞으로는 이 에셋 하나만 고치면 게임 화면 색상 톤 전체가 한 번에 통일됩니다.

- 게임 종료 결과 패널의 텍스트/버튼, HUD 우측 상단 설정 버튼, 건물 배치/유닛 생산/액션 팝업,
  멀티플레이 재경기 요청 팝업의 RectTransform 앵커를 부모 비율 기반으로 변경했습니다.
  그 결과 작은 폰부터 큰 태블릿까지 동일한 비율로 늘어나며, 작거나 비좁아 보이던 UI가
  해상도에 맞춰 자연스럽게 커지게 됩니다.

- 포기 확인 팝업의 확인/취소 버튼 배경 색상이 자동으로 적용되도록 ConfirmPopup 컴포넌트를
  보강했습니다. 이전에는 디자이너가 직접 색상을 설정해야 했지만, 이제는 색상 설정 에셋만
  연결하면 컴포넌트가 자동으로 색을 입혀줍니다.

이 작업은 모든 색상/레이아웃 FAIL 9건을 동시에 해결하기 위한 일괄 패치이며,
변경 후에는 실기기에서 아래 테스트 케이스를 통해 정상 동작을 확인합니다.

### TC-SINGLE-HUD-007: HUD 설정 버튼 크기 확인

**전제:** 싱글플레이 게임을 시작하여 인게임 화면이 표시되어 있다.

**동작:**
1. 게임 화면 상단 HUD 영역을 본다.
2. 우측 상단에 위치한 톱니바퀴 모양의 설정 버튼을 확인한다.
3. 버튼이 다른 HUD 텍스트(골드, 인구, 타일 카운트)와 어우러져 화면에 자연스럽게 자리 잡고 있는지 본다.
4. 같은 게임을 다양한 화면 비율의 기기(폰, 큰 태블릿 등)에서 실행해 본다.

**기댓값:**
- 설정 버튼이 HUD 상단 바의 우측 끝에서 적당한 여백을 두고 배치된다.
- 버튼의 크기가 HUD 바의 세로 높이에 비례하여 충분히 커서 손가락으로 누르기 쉽다.
- 버튼이 너무 작아서 누르기 어렵거나, 너무 커서 HUD 바를 침범하지 않는다.
- 화면 비율이 달라져도 버튼이 항상 HUD 바의 우측 끝 부근에 같은 비율로 위치한다.

**결과:** 인게임화면은 Safe Area를 별도로 고려하여 화면을 그리고 있지 않기 때문에 설정버튼도 역시 safe area와 무관하게 배치하는게 맞음

### TC-SINGLE-BP-001: 건물 배치 팝업 높이 확인

**전제:** 싱글플레이 게임을 시작하여 자신의 팀이 소유한 빈 타일을 한 개 선택할 수 있는 상태이다.

**동작:**
1. 자신의 팀(블루) 영역에 있는 빈 타일을 탭한다.
2. 화면 하단에 건물 배치 팝업이 슬라이드 인 애니메이션과 함께 등장한다.
3. 팝업의 위쪽 끝과 아래쪽 끝이 화면의 어느 위치까지 차지하는지 시각적으로 확인한다.

**기댓값:**
- 팝업이 화면의 아래쪽 약 40 퍼센트 영역을 차지하며 충분히 넓다.
- 건물 아이콘 버튼들이 잘리지 않고 모두 한눈에 보인다.
- 팝업의 위쪽 경계가 HUD를 가리지 않는다.
- 팝업 등장/퇴장 슬라이드 애니메이션이 변경 전과 동일하게 자연스럽게 작동한다.

**결과:** 팝업자체 높이는 적절하게 키워졌으나 그 안에 있는 버튼이나 텍스트 레이아웃이 따라가지못하고 망가짐 보내주는 이미지 참고

### TC-SINGLE-BP-002: 건물 배치 팝업 비용 숫자 정렬 확인

**전제:** 건물 배치 팝업이 화면 하단에 표시되어 있다.

**동작:**
1. 각 건물 아이콘 아래에 표시된 골드 비용 숫자를 확인한다.
2. 보유 골드가 비용보다 적은 상태(예: 게임 초반)에서 그 건물의 비용 숫자 색상을 확인한다.
3. 충분히 골드를 모은 뒤 같은 비용 숫자의 색상이 어떻게 바뀌는지 확인한다.
4. 팝업을 닫았다가 다시 열어 색상이 정상적으로 초기화되는지 확인한다.

**기댓값:**
- 보유 골드보다 비용이 비싼 건물의 비용 숫자는 강조 색상(빨간색 톤)으로 표시된다.
- 보유 골드로 살 수 있는 건물의 비용 숫자는 기본 색상(흰색)으로 표시된다.
- 골드가 변할 때마다 색상이 즉시 갱신된다.
- 팝업을 닫았다가 다시 열면 모든 비용 텍스트가 기본 색상에서 시작한다.

**결과:** 텍스트가 좌측으로 치우쳐져 있음 이미지참고

### TC-SINGLE-SET-004: 포기 확인 팝업 버튼 색상 확인

**전제:** 싱글플레이 또는 멀티플레이 인게임 화면에서 HUD 우측 상단의 설정 버튼이 보이는 상태이다.

**동작:**
1. HUD 우측 상단의 설정 버튼을 탭한다.
2. 인게임 설정 메뉴가 표시된다.
3. 설정 메뉴 안의 "포기" 버튼을 탭한다.
4. 화면 중앙에 포기 확인 팝업이 나타난다.
5. 팝업에 표시된 "포기"(확인) 버튼과 "취소" 버튼의 배경 색상을 확인한다.

**기댓값:**
- 포기 확인 팝업의 "포기" 버튼은 확실히 보이는 초록색 톤의 배경을 가진다.
- "취소" 버튼은 확실히 보이는 빨간색 톤의 배경을 가진다.
- 두 버튼은 한눈에 색으로 구분 가능하며, 사용자에게 둘 중 어떤 버튼을 누를지 직관적으로 안내한다.
- 어떤 시점에 팝업을 열어도 두 버튼의 색상이 동일하게 적용된다.

**결과:** PASS

### TC-SINGLE-SET-007: 인게임 설정에서 게임 종료 UI 크기 확인

**전제:** 싱글플레이 인게임에서 HUD 우측 상단의 설정 버튼이 보이는 상태이다.

**동작:**
1. HUD 우측 상단의 설정 버튼을 탭한다.
2. 인게임 설정 메뉴 안의 포기 버튼을 탭한다.
3. 포기 확인 팝업에서 포기 버튼을 탭하여 확정한다.
4. 게임 종료 결과 패널이 표시된다.
5. 결과 텍스트("패배!" 등)의 크기, 다시하기 버튼/로비 복귀 버튼의 크기를 확인한다.

**기댓값:**
- 결과 텍스트가 화면 가로폭의 약 80 퍼센트, 세로 약 13 퍼센트를 차지하여 한눈에 들어온다.
- 다시하기 버튼과 로비 복귀 버튼이 화면 가로폭의 약 70 퍼센트를 차지하여 손가락으로 누르기 쉽다.
- 모든 요소가 작은 폰에서도 충분히 크고, 큰 태블릿에서도 비례하여 커진다.
- 텍스트 색상(패배 시 빨간 톤, 승리 시 파란 톤)이 명확하게 구분된다.

**결과:** 버튼의 크기만 커졌고 버튼 내부 텍스트 및 승리or패배 텍스트와 몇초뒤 로비로 나가진다는 안내 텍스트 크기도 조정이 필요함

### TC-SINGLE-END-001: 게임 종료 UI 크기 확인

**전제:** 싱글플레이 게임이 진행 중이고 자신의 본진(Blue Castle) 또는 적의 본진(Red Castle) 중 하나가
파괴되기 직전이다.

**동작:**
1. 본진 파괴가 일어나도록 게임을 진행한다.
2. 자신의 본진이 파괴되면 패배 화면, 적의 본진이 파괴되면 승리 화면이 표시된다.
3. 결과 텍스트("승리!" 또는 "패배!"), 다시하기 버튼, 로비 복귀 버튼의 크기를 확인한다.
4. 30초 자동 복귀 카운트다운 텍스트가 잘 보이는지 확인한다.

**기댓값:**
- 결과 텍스트가 화면 가로폭의 약 80 퍼센트, 세로 약 13 퍼센트를 차지하여 한눈에 들어온다.
- 결과 텍스트 색상이 승리 시 파란 톤, 패배 시 빨간 톤으로 명확하게 구분된다.
- 다시하기 버튼과 로비 복귀 버튼이 화면 가로폭의 약 70 퍼센트를 차지하여 손가락으로 누르기 쉽다.
- 카운트다운 텍스트가 패널 하단의 정해진 위치에 보인다.

**결과:** 버튼의 크기만 커졌고 버튼 내부 텍스트 및 승리or패배 텍스트와 몇초뒤 로비로 나가진다는 안내 텍스트 크기도 조정이 필요함

### TC-MULTI-END-002: 재경기 요청 팝업 크기 확인

**전제:** 멀티플레이 커스텀 매칭으로 두 명이 같은 방에 입장하여 게임이 종료된 직후 상태이다.

**동작:**
1. 한쪽 플레이어가 게임 종료 화면에서 "다시하기" 버튼을 탭한다.
2. 자신의 화면에는 "재경기 요청 중..." 상태가 표시되고, 상대의 화면에는 재경기 요청 팝업이 뜬다.
3. 상대 화면에 표시된 재경기 요청 팝업의 크기를 확인한다.
4. 상대가 거절 버튼을 누르면, 요청한 쪽의 화면에 거절 안내 팝업이 표시된다.
5. 거절 안내 팝업의 크기도 확인한다.

**기댓값:**
- 재경기 요청 팝업이 화면의 중앙에 위치하며 가로폭의 약 80 퍼센트, 세로의 약 40 퍼센트를 차지한다.
- 메시지 텍스트와 수락/거절 버튼이 모두 손가락으로 누르기 충분한 크기로 표시된다.
- 거절 안내 팝업도 동일한 크기/위치 규격을 따른다.
- 화면 비율이 다른 기기에서도 같은 비율로 늘어나며, 작은 폰에서 잘리거나 큰 태블릿에서 너무 작아 보이지 않는다.

**결과:** 버튼의 크기만 커졌고 버튼 내부 텍스트 및 레이아웃 비율 조정 필요함
