# Testcase — UI 규칙 준수 수정 (Rule 5 CanvasGroup 전환)

이 문서는 **SetActive 호출을 CanvasGroup 전환 방식으로 교체한 뒤**, 로비 화면 전환이 기존과 동일하게 동작하는지 확인하기 위한 테스트 케이스 모음입니다.
수정 대상은 로비 7개 뷰이며, 각 뷰의 보이기/숨기기 동작이 시각적으로 이전과 차이 없어야 합니다.

---

## 테스트 환경

- Unity 에디터 Play Mode
- 멀티플레이 연결 불필요 (로비 UI 단독 동작 확인)

### 정적 분석 체크포인트

- 각 파일에서 `SetActive` 호출이 완전히 제거되었는지 확인 (주석 제외)
- CanvasGroup alpha=0 설정 시 blocksRaycasts=false, interactable=false 도 함께 설정되는지 확인
- CanvasGroup alpha=1 설정 시 blocksRaycasts=true, interactable=true 도 함께 설정되는지 확인
- Awake에서 CanvasGroup을 가져오는 코드가 각 파일에 존재하는지 확인
- CanvasGroup이 이미 존재할 때 중복 추가되지 않는지 확인 (TryGetComponent → AddComponent 패턴)
- LobbyRootView: 4개 패널(전투/상점/프로필/랭킹) 각각에 독립적인 CanvasGroup이 연결되는지 확인
- CustomHostView: 뷰 자체 CanvasGroup 외에 에러 텍스트 오브젝트에도 별도 CanvasGroup이 연결되는지 확인
- RandomMatchView: 뷰 자체 CanvasGroup 외에 취소 버튼 오브젝트에도 별도 CanvasGroup이 연결되는지 확인
