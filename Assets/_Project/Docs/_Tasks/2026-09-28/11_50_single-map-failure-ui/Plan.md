## 1. 이 계획이 무엇을 하는가 (자연어 설명 — CLAUDE.md 규칙 13)

혼자 하는 게임에서 **새 지도를 만들지 못했을 때 화면이 아무 말도 하지 않고 사용자를 가둬 두는 문제**를 없앤다.

지금은 두 상황이 모두 조용히 실패한다.

1. **경기를 처음 시작할 때** 지도를 못 만들면 → 땅이 안 그려진 **텅 빈 전투 화면**만 남는다. 안내도, 나갈 방법도 없다.
2. **경기가 끝난 뒤 「다시하기」를 눌렀을 때** 못 만들면 → **결과 화면도 지도도 안내도 없다.** 결과 화면에 있던 「로비로」 버튼까지 사라져서 **스스로 나갈 방법이 아예 없다.**

그래서 이 계획은 네 가지를 한다.

- **첫 경기 실패**에는 이미 이 프로젝트에서 쓰고 있는 **확인/취소 팝업**(「다시하기」/「로비로」 두 버튼)을 띄운다. **새 UI 를 만들지 않는다.**
- **다시하기 실패**에는 **결과 화면을 되살려서**, 그 화면에 이미 있는 안내 줄에 `맵 준비에 실패했습니다.` 한 줄을 띄운다. 결과 화면에는 「다시하기」와 「로비로」가 이미 있으니 사용자가 갇히지 않는다.
- 그러려면 지도 만들기 함수가 **성공했는지 실패했는지를 부르는 쪽에 알려 주어야** 한다. 지금은 알려 주지 않는다. 그 **신호 하나를 추가**한다.
- 🔴 **그리고 혼자 하는 게임에서는 「몇 초 뒤에 자동으로 로비로 돌아갑니다」 시계를 아예 돌리지 않는다**(사용자 확정). 혼자 하는 게임에는 기다릴 상대가 없으니 사용자를 재촉할 이유가 없고, 나가는 버튼이 늘 켜져 있어서 **시계가 없어도 갇히지 않는다.** 🔴 **둘이 하는 게임(멀티)은 지금과 똑같이 그대로 둔다.**

## 2. ✅ 사용자 확정 — 싱글플레이의 타이머는 전면 제거한다

**사용자 발언(전달값)** — *"싱글플레이는 멀티플레이와 다르게 타이머설정이 필요가 없어"*. 제시된 선택지 중 **「싱글은 타이머 전면 제거」**를 명시적으로 골랐다.

### 2-1. 확정된 싱글 화면

```
[싱글 평시]   상태 줄: (빈 줄)
              [ 다시하기 ]  [ 로비로 ]     → 자동 복귀 없음

[싱글 실패]   상태 줄: 맵 준비에 실패했습니다.
              [ 다시하기 ]  [ 로비로 ]     → 자동 복귀 없음
```

- 🔴 **평시·실패 구분 없이 싱글에는 자동 복귀가 없다.** 사용자가 **두 버튼으로 직접** 나간다.
- 🔴 **타이머를 없앨 수 있는 근거는 규칙 D-3 이다** — *「로비 복귀 버튼은 어떤 상태에서도 비활성화하지 않는다」* · *「두 버튼이 동시에 꺼지면 사용자가 스스로 화면을 빠져나갈 방법이 없어진다」*. **나가는 길이 늘 열려 있으므로 시간 제한이 사용자를 구조할 필요가 없다.**
- 🔴 **멀티는 무변경이다** — 규칙 **D-1 · D-2 · D-4 · D-7 · M-2 · M-3** 과 60초/30초 동작은 **전부 그대로**다. 검증 항목에 **멀티 회귀 확인**을 넣었다(§8-1 의 3·4·7).

### 2-2. ✅ 파생 결정 2건이 닫힌다

| 항목 | 결론 | 근거 |
|------|------|------|
| **상태 줄 문구에 남은 초를 붙일 것인가** | ✅ **붙이지 않는다.** 싱글 실패 문구는 **`맵 준비에 실패했습니다.` 한 줄**이다 | 🔴 **개행 규약의 예외가 아니라 「나눌 자리 자체가 없는 것」이다.** 규칙 D-7 의 2026-09-27 확정 블록은 개행을 **「남은 초 바로 앞에서」** 넣도록 정했고, 같은 블록이 **알림 팝업 본문을 대상에서 뺀 이유**도 *"그 본문에는 남은 초가 들어가지 않는다 … 나눌 자리 자체가 없다"* 였다. 평시 문구가 한 줄인 사유(*"앞에 올 문장이 없다"*)와 **같은 부류의 판단**이다 |
| **재경기 실패 시 카운트다운을 몇 초로 재시작할 것인가** | 🔴 **무효 — 재시작 자체가 없다** | 🔴 **「정하지 않았다」가 아니다.** 싱글에 시계가 없어지므로 **재시작할 대상이 사라져 전제가 무효**가 됐다. ⚠️ **멀티의 전체 길이 재시작(규칙 M-3)은 그대로 살아 있다** |

⚠️ **종전 권고안 2개(「초를 붙인다」 · 「60초 전체 길이 재시작」)는 이 확정으로 폐기됐다.** 그 둘은 **「싱글에도 타이머가 있다」는 전제 위에서만 성립**했다.
