## TC 목록

### TC-1: 근접 유닛이 성 타일까지 접근하여 공격을 시작한다
**ID**: SINGLE-001  
**분류**: 핵심 — 이번 작업의 메인 기능

**전제조건**
- Spirit 종족으로 게임 시작
- 배럭에서 근접 유닛(FlameSpirit 또는 EmberSpirit) 1기 생산 완료

**절차**
1. 근접 유닛을 선택한다.
2. 적 본기지(Castle) 방향으로 이동 명령을 내린다.
3. 유닛이 이동하는 것을 관찰한다.
4. 유닛이 Castle 인접 타일에 도달한 이후의 동작을 관찰한다.

**기댓값**
- [ ] 유닛이 Castle 인접 타일에서 멈추지 않고, **Castle 타일 방향으로 계속 이동**한다.
- [ ] 이동 중 Castle까지 거리가 가까워지는 시점에 **공격 애니메이션**이 시작된다.
- [ ] Castle의 HP가 감소한다.

**결과**: PASS

### TC-2: 근접 유닛 여러 기가 연속으로 성에 접근하여 공격한다
**ID**: SINGLE-002  
**분류**: 핵심 — ClaimedTile 버그 수정 검증

**전제조건**
- Spirit 종족으로 게임 시작
- 배럭에서 근접 유닛(FlameSpirit) **2기 이상** 생산 완료

**절차**
1. 첫 번째 근접 유닛을 Castle 방향으로 이동시킨다.
2. 첫 번째 유닛이 Castle에 도달하여 공격 상태가 되는 것을 확인한다.
3. 첫 번째 유닛이 공격 중인 상태에서 두 번째 근접 유닛을 Castle 방향으로 이동시킨다.
4. 두 번째 유닛의 이동을 관찰한다.

**기댓값**
- [ ] 두 번째 유닛이 인접 타일에서 멈추지 않고 Castle 방향으로 접근한다.
- [ ] 두 번째 유닛도 공격 상태로 전환된다.
- [ ] 세 번째 유닛도 동일하게 동작한다 (가능하면 추가 확인).

**결과**: PASS

### TC-3: Spirit 종족 선택 시 생산 패널에 Spirit 유닛이 표시된다
**ID**: SINGLE-003  
**분류**: 핵심 — 종족별 생산 패널 동적 바인딩

**전제조건**
- Spirit 종족으로 게임 시작

**절차**
1. 배럭을 건설한다.
2. 배럭 클릭 후 생산 패널을 연다.
3. 버튼 3개의 아이콘과 유닛 종류를 확인한다.
4. 버튼을 클릭하여 유닛 생산을 시도한다.
5. 스폰된 유닛의 외형을 확인한다.

**기댓값**
- [ ] 생산 패널에 Spirit 유닛(FlameSpirit / EmberSpirit / InfernoSpirit)이 표시된다.
- [ ] Human 유닛(Pistoleer 등)이 표시되지 않는다.
- [ ] 생산된 유닛이 Spirit 유닛 프리팹으로 스폰된다.
- [ ] 콘솔에 `프리팹이 설정되지 않았습니다` 에러가 출력되지 않는다.

**결과**: 생산패널 스프라이트가 아직 준비되지 않았으나, 선택된 종족이 생성됨

### TC-5: 근접 유닛이 적 유닛을 향해 직진 경로로 이동한다
**ID**: SINGLE-005  
**분류**: 회귀 — 적 Position blocked 제거 검증

**전제조건**
- Spirit 종족으로 게임 시작
- 아군 근접 유닛(FlameSpirit)과 적 유닛이 거의 정면에 위치하는 상황

**절차**
1. 근접 유닛을 적 유닛이 있는 방향(Castle 방향)으로 이동시킨다.
2. 이동 경로를 관찰한다.

**기댓값**
- [ ] 근접 유닛이 적 유닛을 빙 돌아가지 않고 직진 방향으로 이동한다.
- [ ] 이동 중 적 유닛과 가까워지면 공격 상태로 전환된다.

**결과**: PASS

### TC-6: Human 종족 원거리 유닛이 정상 동작한다 (회귀)
**ID**: SINGLE-006  
**분류**: 회귀 — 기존 유닛 동작 유지 확인

**전제조건**
- Human 종족으로 게임 시작
- Pistoleer 또는 Sniper 생산 완료

**절차**
1. Human 원거리 유닛을 Castle 방향으로 이동시킨다.
2. 적 유닛 또는 Castle에 접근하는 것을 관찰한다.
3. 공격이 시작되는 시점과 위치를 확인한다.

**기댓값**
- [ ] 원거리 유닛이 Castle 인접 타일에서 공격을 시작한다 (기존과 동일).
- [ ] 근접 유닛처럼 Castle 타일 방향으로 추가 이동하지 않는다.
- [ ] 콘솔에 에러가 출력되지 않는다.

**결과**: PASS

### TC-7: 멀티플레이에서 근접 유닛 공격이 양쪽 화면에 동기화된다
**ID**: MULTI-001  
**분류**: 멀티플레이 확인

**전제조건**
- Host(에디터) + Client(빌드) 구성
- Host: Spirit 종족 / Client: Human 종족 (또는 반대)

**절차**
1. 양쪽에서 게임을 시작한다.
2. Host에서 Spirit 근접 유닛(FlameSpirit)을 생산하여 Castle 방향으로 이동시킨다.
3. Host 화면에서 FlameSpirit이 Castle에 접근하여 공격하는 것을 확인한다.
4. Client 화면에서 동일 유닛의 동작을 확인한다.

**기댓값**
- [ ] Host와 Client 양쪽에서 FlameSpirit이 Castle 방향으로 이동 후 공격한다.
- [ ] 공격 애니메이션이 양쪽에서 동시에 재생된다.
- [ ] Castle HP가 양쪽 화면에서 동일하게 감소한다.

**결과**: PASS
