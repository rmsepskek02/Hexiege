# UI 구상도: 로그인 시스템 (Login.unity)

로그인 시스템에 포함되는 모든 화면의 레이아웃 구상도입니다. Hexiege는 모바일 세로 모드(9:16) 게임이므로 모든 화면은 세로 레이아웃을 기준으로 합니다. 아래 ASCII 구상도는 각 화면에 어떤 요소가 어떤 순서로 배치되는지를 나타냅니다. 실제 디자인 에셋(색상, 폰트, 이미지)은 추후 결정합니다.

---

## 공통 사항

- 전체 배경: 게임 테마에 맞는 단색 또는 배경 이미지
- 패널 전환: 단순 SetActive 전환 (DOTween 애니메이션은 선택 사항)
- 모든 화면에 게임 로고 또는 제목 텍스트 상단 표시
- 오류/안내 메시지는 각 화면 하단의 StatusText에 표시
- 로딩 인디케이터: 비동기 작업 중 버튼 비활성화 + 로딩 스피너 표시

## 1. 로그인 선택 화면 (LoginSelectView)

자동 로그인 실패 시 표시되는 첫 화면. 세 가지 로그인 방식을 선택할 수 있습니다.

```
┌─────────────────────────┐
│                         │
│                         │
│    ┌─────────────────┐  │
│    │   HEXIEGE 로고   │  │
│    └─────────────────┘  │
│                         │
│                         │
│                         │
│  ┌───────────────────┐  │
│  │  G  Google로 로그인│  │  ← 구글 아이콘 + 텍스트
│  └───────────────────┘  │
│                         │
│  ┌───────────────────┐  │
│  │  ✉  이메일로 로그인│  │  ← 이메일 아이콘 + 텍스트
│  └───────────────────┘  │
│                         │
│  ─────── 또는 ──────────  │
│                         │
│      익명으로 시작하기    │  ← 작은 텍스트 버튼 (하단 강조 낮음)
│                         │
│                         │
│   [StatusText 오류표시]  │
└─────────────────────────┘
```

**Inspector 컴포넌트**:
- `_googleLoginButton` (Button) — Google 로그인
- `_emailLoginButton` (Button) — 이메일 로그인/회원가입 화면으로
- `_anonymousButton` (Button) — 익명 경고 팝업 표시
- `_statusText` (TextMeshProUGUI) — 오류 메시지

## 2. 익명 로그인 경고 팝업 (AnonymousWarningPopup)

익명으로 시작하기 클릭 시 로그인 선택 화면 위에 오버레이로 표시.  
팝업 외부 클릭으로는 닫히지 않음 — 반드시 버튼으로 선택해야 함.

```
┌─────────────────────────┐
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │  ← 반투명 배경 오버레이
│  ▓  ┌───────────────┐ ▓  │
│  ▓  │  ⚠  주의       │ ▓  │
│  ▓  │               │ ▓  │
│  ▓  │ 익명으로 시작  │ ▓  │
│  ▓  │ 하면 기기 변경 │ ▓  │
│  ▓  │ 또는 앱 재설치 │ ▓  │
│  ▓  │ 시 게임 데이터 │ ▓  │
│  ▓  │ 를 잃을 수     │ ▓  │
│  ▓  │ 있습니다.      │ ▓  │
│  ▓  │               │ ▓  │
│  ▓  │ ┌───────────┐ │ ▓  │
│  ▓  │ │ 계정 만들기│ │ ▓  │  ← 이메일 회원가입 화면으로
│  ▓  │ └───────────┘ │ ▓  │
│  ▓  │               │ ▓  │
│  ▓  │ ┌───────────┐ │ ▓  │
│  ▓  │ │계속 익명으로│ │ ▓  │  ← 익명 로그인 후 Lobby 이동
│  ▓  │ │   진행    │ │ ▓  │
│  ▓  │ └───────────┘ │ ▓  │
│  ▓  └───────────────┘ ▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
└─────────────────────────┘
```

**Inspector 컴포넌트**:
- `_warningText` (TextMeshProUGUI) — 경고 메시지
- `_createAccountButton` (Button) — 이메일 회원가입 화면으로
- `_continueAnonymousButton` (Button) — 익명 로그인 진행

## 5. 이메일 인증 대기 화면 (EmailVerifyView)

회원가입 완료 직후 또는 이메일 미인증 계정 로그인 시도 시 표시.

```
┌─────────────────────────┐
│                         │
│       이메일 인증         │
│                         │
│          ✉️              │  ← 메일 아이콘 (큰 사이즈)
│                         │
│   인증 메일이 발송        │
│   되었습니다.             │
│                         │
│   [이메일 주소 표시]      │  ← 발송된 메일 주소 (회색 텍스트)
│                         │
│   메일함을 확인하고       │
│   인증 링크를 클릭해      │
│   주세요.                 │
│                         │
│  ┌─────────────────────┐│
│  │    인증 완료 확인    ││  ← Firebase 재확인 후 Lobby 이동
│  └─────────────────────┘│
│                         │
│  ┌─────────────────────┐│
│  │   인증 메일 재발송   ││
│  └─────────────────────┘│
│                         │
│   [StatusText 안내/오류] │
└─────────────────────────┘
```

**Inspector 컴포넌트**:
- `_emailText` (TextMeshProUGUI) — 발송된 이메일 주소 표시
- `_checkVerifyButton` (Button) — 인증 상태 재확인 → 완료 시 Lobby 이동
- `_resendButton` (Button) — 인증 메일 재발송
- `_statusText` (TextMeshProUGUI)

## 7. 앱 종료 확인 팝업

```

│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │

│  ▓  │  앱을 종료하시  │ ▓  │
│  ▓  │   겠습니까?    │ ▓  │
│  ▓  │               │ ▓  │
│  ▓  │ ┌─────┐┌─────┐│ ▓  │
│  ▓  │ │취 소││종 료 ││ ▓  │
│  ▓  │ └─────┘└─────┘│ ▓  │
│  ▓  └───────────────┘ ▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
└─────────────────────────┘
```

**구현 방식**:
- 기존 `ConfirmPopup.cs` 재사용
- 취소: 팝업 닫기
- 종료: `Application.Quit()`

## 9. ProfileView — Lobby 씬 Profile 탭

기존 Lobby 씬 Profile 탭에 추가. 현재 `ProfileView.cs`는 빈 파일.

### 익명 계정 로그인 상태
```
┌─────────────────────────┐
│         프로필            │
│                         │
│  현재 익명으로 로그인    │
│  중입니다.               │
│                         │
│  계정을 연동하면 기기    │
│  변경 시에도 데이터를    │
│  유지할 수 있습니다.     │
│                         │
│  ┌─────────────────────┐│
│  │   G  Google로 연동   ││
│  └─────────────────────┘│
│                         │
│  ┌─────────────────────┐│
│  │   ✉  이메일로 연동   ││
│  └─────────────────────┘│
│                         │
│  ───────────────────────│
│                         │
│  ┌─────────────────────┐│
│  │       로그아웃        ││
│  └─────────────────────┘│
└─────────────────────────┘
```

### 실계정 로그인 상태 (Google 또는 이메일)
```
┌─────────────────────────┐
│         프로필            │
│                         │
│  [Google 계정명]         │  ← 또는 이메일 주소

│  └─────────────────────┘│
└─────────────────────────┘
```

**Inspector 컴포넌트** (ProfileView.cs):
- `_accountInfoText` (TextMeshProUGUI) — 계정 정보 또는 "익명" 안내
- `_linkGoogleButton` (Button) — Google 연동 (익명 계정만 표시)
- `_linkEmailButton` (Button) — 이메일 연동 (익명 계정만 표시)
- `_logoutButton` (Button) — 로그아웃 후 Login 씬 이동
- `_anonymousSection` (GameObject) — 익명 계정 전용 영역 (연동 버튼 포함)
