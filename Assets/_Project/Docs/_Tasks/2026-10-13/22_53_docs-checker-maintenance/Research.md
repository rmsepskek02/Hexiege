## 5. 링크 범위와 오탐 위험

현재 `RE_LINK`는 `.md` 대상으로만 한정된다. `missing.txt`가 추출되지 않는 것도 확인했다. 다만 이번 정비에서 모든 확장자의 로컬 링크를 즉시 오류로 바꾸면 과거 원문 보존용 raw `.txt` 출처나 UI 예시 표기를 실제 이동 링크로 오인할 수 있다.

우선 Markdown 파일 연결과 같은 문서·다른 문서의 앵커를 정비한다. 명시적 HTML 앵커, 한글·이모지 제목, 중복 제목 접미사, URL 인코딩, 공백 경로를 테스트로 고정해야 한다. 자동 제목 앵커 규칙은 저장소에서 사용하는 링크와 일치하도록 명시한다. 지원하지 않는 형식은 검사한 것으로 표시하지 않는다. HTTP 등 외부 링크의 네트워크 확인은 이번 범위가 아니다.

문서 예시·코드 블록의 가상 정의와 실제 정의, 이력의 인용과 현행 참조는 구별해야 한다. 기존 `_Tasks/`·`_Logs/` 제외와 `.claude/skills`·`plugins`·`worktrees` 제외를 유지한다. 구문 지원을 넓히는 과정에서 외부 문서나 이력을 소급 교정하지 않는다.

## 6. 보존할 동작과 테스트 현황

- 기존 CLI: `--root`, `--memory-root`, `--claude-root`, `--no-claude-docs`, `--update-baseline`, `--reason`.
- 기본 읽기 전용, 오류 종료 코드, 기준값 명시 갱신 경로, 사유 없는 감소 갱신 거부, 기존 `change_log`·`known_orphans` 및 설명 키 보존을 유지한다.
- 고아 토픽과 전체 행수 검사에서 사용하는 동일 수집 기준을 유지한다. 현재 증가 안내는 오류와 분리되어 있으며 검사기 정비를 핑계로 실제 기준값을 변경하지 않는다.
- `rg --files Tools` 및 `rg --files -g '*test*' -g '*Test*' Tools`로 확인한 범위에서는 검사기 테스트 파일이 없다. 저장소 전체 모든 테스트의 부재를 주장하지 않는다.
- 본문 의미·게임 구현값·밸런싱·AI 시나리오 적절성은 기계적 참조 검사와 별개다. [5]의 낱말 겹침은 의미 정확성 증명이 아니며 한계를 계속 표시해야 한다.
