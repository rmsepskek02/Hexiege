# Testcase — Production 잠금 유닛 Lock Icon 표시

업그레이드가 필요한 유닛 버튼에 잠금 상태를 시각적으로 표시하는 기능의 검증 결과를 담는다.
초상화 디밍(어둡게)과 우측 하단 자물쇠 아이콘 배지가 올바르게 동작하는지, 건물 업그레이드 후 잠금이 해제되는지를 확인한다.

---

### SINGLE-001: 1단계 건물에서 잠금 유닛 시각 표시 확인

**전제:** 싱글플레이 게임에서 1단계 생산건물(TrainingCamp)이 배치된 상태.

**동작:**
1. 1단계 생산건물을 클릭하여 생산 패널을 연다.
2. 유닛 버튼 슬롯 3개의 상태를 확인한다.

**기댓값:**
- 슬롯0(1단계 유닛): 잠금 없음 — 초상화 정상 색상, 자물쇠 아이콘 미표시.
- 슬롯1(2단계 유닛): 초상화가 어둡게 표시되고, 우측 하단에 자물쇠 아이콘이 표시된다.
- 슬롯2(3단계 유닛): 초상화가 어둡게 표시되고, 우측 하단에 자물쇠 아이콘이 표시된다.

**결과:** PASS

---

### SINGLE-002: 잠금 유닛 탭 시 토스트 표시 확인

**전제:** SINGLE-001 완료 후 생산 패널이 열린 상태.

**동작:**
1. 잠금 표시된 유닛 버튼(슬롯1 또는 슬롯2)을 탭한다.

**기댓값:**
- 생산이 등록되지 않는다.
- "건물 업그레이드가 필요합니다" 토스트가 표시된다.

**결과:** PASS

---

### SINGLE-003: 건물 업그레이드 후 잠금 해제 확인

**전제:** 싱글플레이 게임에서 1단계 생산건물이 배치되고 업그레이드 비용 이상의 골드를 보유한 상태.

**동작:**
1. 1단계 생산건물을 클릭하여 생산 패널을 연다.
2. 슬롯1(2단계 유닛)이 잠금 상태임을 확인한다.
3. 패널 하단의 업그레이드 버튼을 클릭한다.
4. 패널이 닫히면 같은 건물을 다시 클릭하여 패널을 다시 연다.

**기댓값:**
- 업그레이드 후 건물 외형이 2단계로 바뀐다.
- 다시 연 패널에서 슬롯1(2단계 유닛)의 자물쇠 아이콘이 사라지고 초상화 색상이 정상으로 복원된다.
- 슬롯0과 슬롯1은 탭하면 생산이 등록된다.
- 슬롯2(3단계 유닛)는 여전히 잠금 상태로 표시된다.

**결과:** PASS

# 정적 분석 결과

### [분석-001] 슬롯 인덱스 매핑 정확성

`UpdateLockIndicators()`의 `slotIndex = i + 1` 오프셋이 `_activeUnitLocks` 배열과 정확하게 대응하는지 확인.

- `_unitLockIndicators[0]` → `slotIndex=1` → `_activeUnitLocks[1]` (2단계 유닛) ← 올바름
- `_unitLockIndicators[1]` → `slotIndex=2` → `_activeUnitLocks[2]` (3단계 유닛) ← 올바름
- 슬롯0(1단계)은 `_unitLockIndicators`에 없어 항상 기본 색상 유지 ← 올바름

판정: **PASS**

### [분석-002] 2유닛 특수 배치 호환성

2유닛 건물(탈것류: Garage, 식물계: SporePatch)에서 더미 슬롯1은 `_activeUnitLocks[1]=false`로 설정되어 잠금 인디케이터가 활성화되지 않음. `slotIndex = i + 1` 매핑에서 슬롯2는 두 번째 실유닛에 올바르게 대응.

판정: **PASS**

### [분석-003] LayoutElement IgnoreLayout 설정

LockIndicator GO에 `LayoutElement.ignoreLayout=true` 적용. Slot GO의 HorizontalLayoutGroup에서 제외되어 BorderOverlay와 동일 방식으로 자유 앵커 배치 동작.

판정: **PASS**
