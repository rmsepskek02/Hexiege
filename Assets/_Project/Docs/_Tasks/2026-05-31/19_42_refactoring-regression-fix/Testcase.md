**동작:**
1. 배럭을 클릭하여 생산 패널을 연다.
2. 유닛 종류를 선택하여 생산 버튼을 누른다.
3. 생산 진행 표시가 채워질 때까지 기다린다.

**기댓값:**

- 생산 시간이 경과하면 배럭 근처에 유닛이 나타난다.
- HUD의 인구수가 1 증가한다.
- HUD의 골드 수치가 해당 유닛의 비용만큼 감소한다.

### SINGLE-003: 유닛 이동 → 적 감지 → 전투 → 적 사망

**전제:** 싱글플레이 게임에서 아군 유닛과 적 유닛(Red팀 AI 또는 사전 배치)이 각각 맵에 존재하는 상태.

**동작:**
1. 아군 유닛을 클릭하여 선택한다.
2. 적 유닛 방향의 타일을 클릭하여 이동 명령을 내린다.
3. 유닛이 이동하다가 적을 감지하면 자동으로 전투를 시작할 때까지 기다린다.
4. 적 유닛의 체력이 0이 될 때까지 전투를 관찰한다.

**기댓값:**
- 유닛이 클릭한 방향으로 이동한다.
- 감지 범위 안에 적이 들어오면 유닛이 전투 애니메이션을 재생하며 공격한다.
- 적 유닛 위에 피해량을 나타내는 부유 텍스트가 표시된다.
- 적 유닛의 체력이 0이 되면 사망 애니메이션 후 제거된다.
- 아군 HUD에 인구수 변화는 없고, 적 제거 후 해당 타일 주변의 소유권이 아군 색으로 바뀐다.
- 콘솔에 오류가 없다.
