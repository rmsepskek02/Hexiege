# 물결의 가호 후속 정리 — Plan

## 무엇을 왜 하나요

물결의 가호 작업을 끝낸 뒤 **사실과 어긋난 글귀 네 군데**를 지금 사실에 맞추는 작은 정리입니다. **게임 동작은 바뀌지 않습니다** — 그래서 사용자가 다시 실기 테스트할 것은 없습니다.

1. 자가 검증이 실패할 때만 나오는 영어 메시지 한 줄에서, 이미 지운 주석을 「주석으로 남아 있다」고 말하는 괄호를 고칩니다(코드 문자열 — 프로그래머 담당).

3. 상태 문서 연막탄 행의 「셋업 도구를 다시 실행한 기록이 없다」를, 2026-11-26 물결의 가호 테스트에서 다시 실행했다는 사실로 고칩니다.
4. 스탯 문서에 지원 스킬 수치 절을 **지금 만들지 않고 밸런싱 작업 때 만든다**는 결정을 로드맵 밸런싱 행에 적습니다.

마지막으로 문서 정합성 검사 0건 · 정적 컴파일 기준값 확인 뒤 main에 병합 · 푸시합니다.
