## 프로젝트 컨셉

> Gemini에게 컨텍스트를 줄 때 아래 내용을 그대로 전달한다.

**Hexiege** — 헥스 타일 기반 1v1 PvP 실시간 전략 게임 (모바일, 세로 모드 9:16)

- 플레이어는 건물 건설 + 유닛 생산으로 상대 본기지(Castle) 파괴가 목표

- 타일 점령으로 영토 확장 → 인구수 확보 → 더 많은 유닛 운용

## 프롬포트 작성 원칙

### 원칙 1 — 프롬포트는 영어, 설명은 한글 병기
Gemini에게 요청할 때 반드시 명시:
```
프롬포트는 영어로 작성하고, 각 항목의 의미를 한글로 설명해줘.
```

### 원칙 2 — 한 번에 작성, Positive / Negative 명확히 구분
프롬포트를 여러 번 나눠서 요청하지 않는다.
**Positive(포함할 요소)** 와 **Negative(제외할 요소)** 를 항상 별도 섹션으로 나눠 작성한다.

```
Positive:
[포함해야 할 요소들]

Negative:
[절대 들어가면 안 되는 요소들]
```

### 원칙 3 — 레퍼런스 이미지 안내 요청
Gemini에게 요청할 때 함께 명시:
```
이 에셋과 스타일이 비슷한 레퍼런스 이미지를 어디서 찾으면 좋을지 알려줘.
(어떤 게임, 어떤 캐릭터/UI, 어떤 키워드로 검색하면 되는지 구체적으로)
```

## 이미지 공통 조건

모든 에셋 종류에 공통으로 적용되는 이미지 조건.

### 배경
```
요청 키워드: pure white background, no background
```
- 3D 에셋: Meshy AI가 주체와 배경을 분리하기 위해 순수 흰색 필수
- UI 에셋: Unity에서 배경 제거가 용이하도록 흰색 또는 투명

### 단일 오브젝트
```
요청 키워드: single object, isolated subject
Negative 키워드: multiple objects in frame, background objects
```
여러 오브젝트가 한 이미지에 있으면 Unity/Meshy에서 개별 사용이 불가능하다.

### 해상도
모든 에셋을 동일한 해상도로 요청해 품질 수준을 일관되게 유지한다.

| 에셋 종류 | 권장 해상도 | 비율 |
|---------|-----------|------|
| 3D 에셋 (유닛 / 건물 / 오브젝트) | 1024 × 1024 | 1:1 정사각형 |
| UI 아이콘 | 1024 × 1024 | 1:1 정사각형 |
| UI 버튼 | 1024 × 1024 | 1:1 정사각형 (Unity 9-Slice로 비율 조정) |
| UI 패널 배경 | 1024 × 1024 | 1:1 정사각형 (Unity 9-Slice로 비율 조정) |

```
요청 키워드: 1024x1024 resolution, square canvas, high resolution
```
