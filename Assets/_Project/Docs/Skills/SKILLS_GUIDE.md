## 코드 작업

### `/code-review`
현재 변경된 코드를 **버그, 단순화, 효율** 관점에서 리뷰합니다.

| 옵션 | 설명 |
|------|------|
| 기본 | 리뷰 결과를 대화창에 출력 |
| `--comment` | GitHub PR에 인라인 댓글로 게시 |
| `--fix` | 리뷰 결과를 실제 코드에 자동 적용 |
| `ultra` | 멀티 에이전트 심층 리뷰 (클라우드 실행, 비용 발생) |

**예시**
```
/code-review
/code-review --fix
/code-review ultra
/code-review ultra 42          ← PR 번호 지정
```

---

### `/simplify`
변경된 코드에서 **재사용, 단순화, 효율** 개선점을 찾아 실제로 적용합니다.
버그 탐지는 하지 않으므로, 버그가 의심된다면 `/code-review`를 사용하세요.

**예시**
```
/simplify
```

---

### `/diagnose`
버그나 성능 저하를 **체계적으로 진단**합니다.
재현 → 최소화 → 가설 → 계측 → 수정 → 회귀 테스트 순서로 진행합니다.

**언제 사용하나요?**
- 원인을 모르는 버그가 발생했을 때
- 특정 상황에서만 재현되는 이상 동작이 있을 때
- 성능이 갑자기 나빠졌을 때

**예시**
```
/diagnose 유닛이 특정 헥스 타일에서 겹치는 버그가 있어
```

---

### `/tdd`
**테스트를 먼저 작성**하고, 이후 구현 코드를 작성하는 TDD 방식으로 개발을 진행합니다.

**예시**
```
/tdd
```

---

### `/review`
PR(Pull Request)을 리뷰합니다.

**예시**
```
/review
```

---

### `/security-review`
코드를 **보안 관점**에서 검토합니다.
인증, 입력값 검증, 권한 처리 등 보안 취약점을 탐지합니다.

**예시**
```
/security-review
```

## 기획 · 설계

### `/design-an-interface`
하나의 모듈에 대해 **여러 가지 설계안을 병렬로 생성**하여 비교할 수 있게 해줍니다.
API 구조나 모듈 인터페이스를 결정하기 전에 선택지를 탐색할 때 유용합니다.

**예시**
```
/design-an-interface 건물 업그레이드 시스템 인터페이스를 설계해줘
```

---

### `/prototype`
설계를 확정하기 전에 **작동 가능한 프로토타입**을 빠르게 만들어 검증합니다.
상태 머신, 데이터 모델, UI 흐름 등을 실제로 실행해보고 싶을 때 사용합니다.

**예시**
```
/prototype 스킬 쿨타임 시스템 프로토타입 만들어줘
```

---

### `/grill-me`
내 계획이나 설계에 대해 **집중 인터뷰** 방식으로 검증합니다.
예상치 못한 엣지 케이스나 의사결정 분기점을 찾아내는 데 도움이 됩니다.

**예시**
```
/grill-me 유닛 전투 시스템 설계를 검토해줘
```

---

### `/grill-with-docs`
기존 도메인 모델과 문서를 기준으로 계획을 검증하고,
결정된 내용을 **CONTEXT.md, ADR 등 문서에 바로 반영**합니다.

**예시**
```
/grill-with-docs
```

---

### `/to-prd`
현재 대화 내용을 바탕으로 **PRD(제품 요구사항 문서)를 자동 생성**하고
이슈 트래커에 게시합니다.

**예시**
```
/to-prd
```

---

### `/to-issues`
논의된 내용을 **GitHub 이슈**로 자동 등록합니다.

**예시**
```
/to-issues
```

---

### `/request-refactor-plan`
코드 리팩터링을 위한 **실행 계획**을 요청합니다.
무엇을 어떻게 바꿀지 계획 단계에서 정리할 때 사용합니다.

**예시**
```
/request-refactor-plan
```

## 프로젝트 관리

### `/qa`
대화형으로 버그를 리포트하면 **GitHub 이슈를 자동 등록**해주는 QA 세션을 시작합니다.
코드베이스를 배경에서 탐색하며 도메인 언어를 파악하면서 이슈를 기록합니다.

**예시**
```
/qa
```

---

### `/triage`
쌓인 이슈들을 **우선순위별로 분류**합니다.

**예시**
```
/triage
```

---

### `/handoff`
현재 대화 내용을 **다른 에이전트에게 넘길 수 있는 핸드오프 문서**로 압축합니다.
세션 전환이나 에이전트 교체 시 컨텍스트를 유지하는 데 사용합니다.

**예시**
```
/handoff
```

---

### `/schedule`
반복 실행이 필요한 작업을 **cron 스케줄로 예약**하거나,
특정 시점에 한 번 실행되도록 예약합니다.

**예시**
```
/schedule 매일 오전 9시에 빌드 상태 확인해줘
/schedule 내일 오후 3시에 이 작업 실행해줘
```

---

### `/loop`
같은 작업을 **일정 간격으로 반복 실행**합니다.
배포 상태 확인, CI 모니터링 등 폴링이 필요한 경우에 사용합니다.

**예시**
```
/loop 5m /code-review       ← 5분마다 code-review 실행
```

## 환경 · 설정

### `/update-config`
`settings.json`을 수정하여 Claude Code의 동작 방식을 변경합니다.
훅(자동화 행동), 권한, 환경변수 설정 등을 다룹니다.

**언제 사용하나요?**
- "X가 실행될 때마다 Y를 해줘" 같은 자동화 규칙을 추가할 때
- 특정 명령어 실행 권한을 허용/차단할 때
- 환경변수를 세팅할 때

**예시**
```
/update-config npm 명령어 실행 허용해줘
/update-config 클로드가 멈출 때 알림 보내줘
```

---

### `/keybindings-help`
**키보드 단축키를 커스터마이즈**합니다.
`~/.claude/keybindings.json`을 수정하여 단축키를 추가하거나 변경합니다.

**예시**
```
/keybindings-help Ctrl+S에 저장 단축키 추가해줘
```

---

### `/git-guardrails-claude-code`
`git push`, `git reset --hard` 등 **위험한 git 명령을 실행 전에 차단**하는 훅을 설정합니다.

> ⚠️ Hexiege 프로젝트는 이미 CLAUDE.md에서 git 명령을 엄격히 제한하고 있습니다.
> 추가 보호가 필요한 경우에만 사용하세요.

**예시**
```
/git-guardrails-claude-code
```

---

### `/fewer-permission-prompts`
자주 사용하는 읽기 전용 도구들을 allowlist에 추가하여
**매번 뜨는 권한 확인 프롬프트를 줄입니다.**

**예시**
```
/fewer-permission-prompts
```

---

### `/setup-pre-commit`
**pre-commit 훅**을 설정합니다.
커밋 전 자동으로 린트, 포맷, 테스트 등을 실행하도록 구성합니다.

**예시**
```
/setup-pre-commit
```

## 기타 · 유틸리티

### `/caveman`
응답을 **초압축 모드**로 전환합니다.
불필요한 수식어, 서문, 예의 표현을 제거하고 핵심만 전달합니다.
토큰 사용량을 약 75% 줄일 수 있습니다.

**예시**
```
/caveman
```

---

### `/run`
프로젝트 앱을 **실제로 실행**하고 변경 사항이 동작하는지 확인합니다.

**예시**
```
/run
```

---

### `/verify`
코드 변경이 **실제로 의도한 대로 동작하는지** 앱을 실행하여 검증합니다.
테스트 코드가 아닌 실제 앱 동작으로 확인합니다.

**예시**
```
/verify
```

---

### `/improve-codebase-architecture`
코드베이스의 **아키텍처 개선 기회**를 탐색합니다.
도메인 언어, ADR 등 기존 문서를 기반으로 리팩터링 방향을 제안합니다.

**예시**
```
/improve-codebase-architecture
```

---

### `/scaffold-exercises`
코드 학습을 위한 **연습 문제를 생성**합니다.

**예시**
```
/scaffold-exercises
```

---

### `/claude-api`
Claude API / Anthropic SDK를 사용하는 앱을 **개발, 디버깅, 최적화**합니다.
프롬프트 캐싱, 툴 사용, 모델 버전 마이그레이션 등을 포함합니다.

**예시**
```
/claude-api
```

---

### `/init`
프로젝트를 **초기 설정**합니다.

**예시**
```
/init
```
