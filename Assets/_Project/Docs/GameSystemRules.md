## 유닛 이동 시스템

### 작업 배경 (2026-04-29)

기존 이동/전투 로직(Phase 0/1/2)을 반복 패치하는 과정에서 고칠수록 다른 부분이 망가지는 현상이 반복됐다. 특히 적 감지 사거리 밖의 유닛들까지 뒤로 이동하는 현상이 추가로 발생했다.

근본 원인: 규칙 없이 패치를 겹겹이 쌓다 보니 조건들이 서로 충돌하는 구조가 됐다.

**설계 방향 결정:**
- 이동/전투 로직을 처음부터 새로 설계한다
- 규칙을 먼저 명확히 정의하고, 코드는 그 규칙을 그대로 옮기는 방식으로 구현한다
- 규칙은 최대한 단순하게 시작하고, 실제로 문제가 생길 때만 최소한으로 추가한다
- 기존 Phase 0(A* 타일 이동)은 정상 동작하므로 유지한다
- Phase 1(직선 추적)과 Phase 2(타일 복귀)를 새로 설계한다

**구현 목표 (3가지):**
1. 근접 유닛이 A*로 성을 향해 이동하다가 적을 감지하면 직선 추적으로 전환한다
2. 같은 타겟 주변에 여러 유닛이 분산해서 접근한다 (12방향 슬롯)
3. 타겟 처리 후 뒤로 돌아가지 않고 앞으로 계속 진행한다

### 이동 규칙

**규칙 1. 기본 목표**
유닛은 스폰된 순간부터 상대방 성을 향해 이동한다.

**규칙 2. 이동 방식**
A*로 경로를 계산하고, 타일에서 타일로 순서대로 이동한다.

**규칙 4. 경로 재계산 시점**
- 평상시: 타일 도착마다 공유 타일 상태를 기반으로 다음 타일을 결정한다
- 건물 건설 / 건물 파괴 시: 해당 시점에 모든 유닛의 경로를 즉시 재계산한다
- 유닛 점유치는 경로 차단으로 보지 않는다. 점유가 가득 찬 타일은 별도 점유 규칙으로 처리한다

**규칙 5. 점유가 가득 찬 타일 처리**
다음 타일의 점유가 가득 찬 경우, 앞쪽(성 방향)에서 가장 가까운 빈 타일로 우회한다.
뒤로 이동하는 우회는 허용하지 않는다.
앞쪽에 빈 타일이 없는 경우 빈 자리가 생길 때까지 현재 위치에서 대기한다.

**규칙 6. 타일 점유 한도**
한 타일의 최대 점유치는 3이다.
유닛 종류마다 점유치가 다르다. (예: 소형 유닛 1, 대형 유닛 2)

**규칙 3. 공유 타일 상태 (Shared Tile State)**
모든 유닛이 접근할 수 있는 타일맵 상태를 서버에서 중앙 관리한다.
유닛이 이동하면 즉시 업데이트되며, 경로 탐색 시 이 정보를 기반으로 판단한다.

담고 있는 정보:
- 어떤 엔티티가 있는가 (유닛 / 건물 / 성)
- 어느 팀인가 (블루 / 레드)
- 점유 수 (이동 경로 계산용)
- 점령 상태 (누구 영역인가)

멀티플레이: 서버에만 존재. 유닛 이동 결정은 서버에서만 이루어지며 클라이언트는 NetworkTransform으로 결과를 받는다.
싱글플레이: 로컬에서 동일한 구조로 동작. 서버/클라이언트 구분 없이 단일 인스턴스로 실행된다.

**규칙 7. 타일 내 시각적 분산**
같은 타일에 여러 유닛이 있을 때 완전히 겹쳐 보이지 않도록 타일 내에서 위치를 분산시킨다.
분산된 위치는 실제 월드 좌표이며, 전투 판정도 이 위치를 기준으로 이루어진다.

**규칙 9. 이동 속도**
이동 속도는 유닛별 스탯으로 개별 관리한다.
A* 타일 이동과 월드 좌표 직선 추적 모두 동일한 이동 속도 스탯을 사용한다.

**규칙 8. 전투 사거리 판정 기준**
전투 사거리 판정은 타일 기준이 아닌 월드 좌표 기준으로 처리한다.
근접 유닛은 A*로 이동하다가 감지 사거리 내에 적이 들어오면 월드 좌표로 적에게 직접 달려가고, 전투 거리에 도달하면 공격한다.

**규칙 10. 이동 슬롯**
A* 이동 중 다음 타일이 결정되는 순간, 해당 타일 내에서 유닛의 분산 위치(이동 슬롯)를 즉시 할당한다.
유닛은 타일 센터가 아닌 할당된 슬롯 위치(월드 좌표)를 이동 목표로 삼는다.
슬롯 위치에 도달하면 타일 도착으로 판정하고 다음 타일로 이동을 시작한다.
타일을 벗어날 때 이동 슬롯은 해제된다.

**규칙 11. 공격 슬롯**
감지 사거리 내에 적이 진입하면 이동 슬롯을 해제하고 공격 슬롯을 할당한다.
공격 슬롯은 적을 중심으로 방향별로 분산된 위치이며, 같은 적을 공격하는 여러 유닛이 겹치지 않도록 각도 기반으로 나눠 갖는다.
유닛은 할당된 공격 슬롯 위치를 목표로 직선 이동하며, 전투 거리에 도달하면 공격한다.
아래 경우에 공격 슬롯을 해제하고 A* 이동을 재개한다:
- 타겟이 처치된 경우
- 타겟이 감지 사거리 밖으로 벗어난 경우

A* 재개 시, 현재 월드 위치 기준으로 성 방향 앞쪽에 있는 타일 중 가장 가까운 타일에서 시작한다.
뒤쪽 타일로 복귀하는 경우는 허용하지 않는다.

**규칙 12. 유닛 사망 시 슬롯 해제**
유닛이 사망하면 점유 중인 이동 슬롯과 공격 슬롯을 즉시 해제한다.
해제하지 않으면 해당 슬롯이 영구적으로 막혀 다른 유닛이 사용할 수 없게 된다.

### 전투 연계 규칙

**규칙 13. 유닛 타입별 전투 진입**
근접 유닛: 감지 사거리 내에 적이 진입하면 이동 슬롯을 해제하고 공격 슬롯으로 달려간다.
원거리 유닛: 공격 사거리 내에 적이 진입하면 현재 위치(이동 슬롯)에서 멈추고 즉시 공격한다. 별도 공격 슬롯 이동 없이 이동 슬롯 위치가 그대로 공격 위치가 된다.
모든 유닛은 공격 중 이동하지 않는다.

**규칙 14. 타겟 선택**
처음 감지된 적을 타겟으로 삼는다.
타겟을 처치한 후에는 사거리 내에서 가장 가까운 적을 다음 타겟으로 선택한다.
사거리 내에 적이 없으면 A* 이동을 재개한다.

**규칙 15. 전투 종료 후 A* 재개**
근접 유닛: 공격 슬롯을 해제하고 현재 월드 위치 기준으로 성 방향 앞쪽에서 가장 가까운 타일에서 A*를 재개한다.
원거리 유닛: 이동 슬롯을 유지한 채 공격했으므로 전투 종료 시 별도 처리 없이 현재 이동 슬롯 위치에서 A*를 바로 재개한다.

**규칙 16. 범위 공격 (AoE)**
범위 공격은 대미지 계산 방식의 차이이며, 이동 및 슬롯 규칙은 유닛 타입(근접/원거리)에 따른 기존 규칙을 그대로 따른다.
아군에게는 대미지를 주지 않는다.

### 슬롯 분산 규칙

**규칙 17. 이동 슬롯 배치**
타일 내 이동 슬롯은 삼각형 배치로 고정한다.
- 슬롯 1번: 성 방향 앞쪽 중앙
- 슬롯 2번: 뒤쪽 좌측
- 슬롯 3번: 뒤쪽 우측

슬롯 배정 기준: 유닛의 현재 위치에서 가장 가까운 빈 슬롯에 배정한다.
거리가 같을 경우 슬롯 번호 우선순위(1 → 2 → 3) 순서로 배정한다.

점유치 2짜리 유닛은 물리적으로 슬롯 1개를 차지하되, 점유 카운트는 2로 산정한다.
슬롯 배치가 바뀌어도 이미 점유 중인 유닛의 위치는 변경하지 않는다.

**규칙 18. 공격 슬롯 배치**
공격 슬롯은 적의 월드 좌표를 중심으로 12방향(30° 간격) 각도 기반으로 분산 배치한다.
유닛은 접근 방향과 가장 가까운 각도의 빈 슬롯에 배정된다.
앞쪽 슬롯이 모두 찬 경우 순차적으로 측면, 뒤쪽 슬롯이 배정되어 자연스러운 포위 형태가 된다.
공격 슬롯은 타일 점유 시스템과 완전히 별개이며 A* 경로 탐색에 영향을 주지 않는다.
공격 슬롯 위치와 인접 타일 이동 슬롯의 시각적 겹침은 테스트 후 개선한다.
